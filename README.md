# Canada Wide Parking — Kiosk redesign prototype

Interactive prototype of a redesigned pay-station screen (Flowbird hardware) for a university UX project.

## Live prototype
Open `index.html` in any browser, or publish with GitHub Pages / Vercel (no build step).

## How to use
- **Tester controls** (grey panel at the top): choose the card outcome (Approved, Insufficient funds, Unreadable), then press **Insert card** on the payment screen. **Restart prototype** returns to the start.
- **Kiosk buttons**: click or tap the red, yellow and green physical buttons.
- **Licence plate**: type on your keyboard. On a phone, tap the kiosk screen to open the keyboard.
- Desktop shortcuts: Enter = green, Esc = red, F1–F4 = yellow buttons.

## Files
- `index.html` — the complete prototype (all CSS, JS, images and font embedded).
- `.nojekyll` — tells GitHub Pages to serve the file as-is.
- `vercel.json` — static deploy settings for Vercel.
